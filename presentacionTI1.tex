	\begin{frame}{Que es un Lenguaje de Programacion?}
		Un \textbf{lenguaje de programacion} es el medio formal que permite a un ser humano
		comunicar instrucciones a una computadora. Segun su nivel de abstraccion respecto
		al hardware, se clasifican en dos grandes categorias:
		\vspace{0.3cm}
		\begin{columns}
			\column{0.48\textwidth}
			\begin{block}{Alto Nivel}
				Proximo al lenguaje humano. Abstracto, legible y portable. El programador
				no necesita conocer la arquitectura interna del procesador.
			\end{block}
			\column{0.48\textwidth}
			\begin{block}{Bajo Nivel}
				Proximo al lenguaje maquina. Controla directamente el hardware. Requiere
				conocimiento especializado en arquitectura computacional.
			\end{block}
		\end{columns}
		\vspace{0.3cm}
		\centering
		\textit{\small ``A mayor abstraccion, mayor cercania al razonamiento humano
			y mayor distancia del hardware.''}
	\end{frame}
	
	% ============================================================
	% DIAPOSITIVA 2
	% ============================================================
	\begin{frame}{Lenguaje de Alto Nivel --- Definicion}
		Un \textbf{lenguaje de alto nivel} esta disenado para ser comprensible por los seres
		humanos. Su sintaxis se asemeja al lenguaje natural, permitiendo al programador
		enfocarse en la logica del problema sin preocuparse por los detalles del hardware.
		\vspace{0.25cm}
		\begin{block}{Caracteristicas principales}
			\begin{itemize}
				\item \textbf{Abstraccion del hardware:} oculta registros, direcciones de memoria
				y llamadas al sistema operativo.
				\item \textbf{Portabilidad:} el mismo codigo se ejecuta en distintas plataformas
				con minimas modificaciones.
				\item \textbf{Gestion automatica de memoria:} muchos incluyen
				\textit{garbage collection}.
				\item \textbf{Bibliotecas y \textit{frameworks}:} ecosistema amplio que
				acelera el desarrollo.
			\end{itemize}
		\end{block}
		\vspace{0.2cm}
		\small \textbf{Ejemplos:} Python, Java, JavaScript, C\#, Ruby, PHP.
	\end{frame}
	
	% ============================================================
	% DIAPOSITIVA 3
	% ============================================================
	\begin{frame}{Lenguaje de Bajo Nivel --- Definicion}
		Un \textbf{lenguaje de bajo nivel} opera cerca del lenguaje maquina. Sus instrucciones
		se corresponden de forma directa con las operaciones ejecutadas por el procesador.
		La abstraccion es minima o nula.
		\vspace{0.25cm}
		\begin{columns}
			\column{0.48\textwidth}
			\begin{block}{Lenguaje Maquina}
				Primer nivel: instrucciones representadas en binario (0s y 1s). Es el unico
				lenguaje que el procesador ejecuta de forma nativa, sin ninguna traduccion
				intermedia.
			\end{block}
			\column{0.48\textwidth}
			\begin{block}{Lenguaje Ensamblador}
				Segundo nivel: usa codigos mnemotecnicos como \texttt{MOV}, \texttt{ADD},
				\texttt{INT}. Requiere un \textit{ensamblador} para traducirse a codigo
				maquina binario.
			\end{block}
		\end{columns}
		\vspace{0.25cm}
		\small \textbf{Ejemplos:} NASM (x86/Linux), MASM (Windows), GAS, ARM Assembly.
	\end{frame}
	
	% ============================================================
	% DIAPOSITIVA 4
	% ============================================================
	\begin{frame}{Alto Nivel --- Ventajas y Desventajas}
		\begin{columns}
			\column{0.48\textwidth}
			\begin{block}{\textcolor{unemiNaranja}{$\checkmark$}\ Ventajas}
				\begin{itemize}
					\item Sintaxis legible y cercana al lenguaje humano.
					\item Desarrollo mas rapido y menos propenso a errores.
					\item Gran portabilidad entre plataformas.
					\item Comunidad amplia y abundante documentacion.
					\item Gestion automatica de recursos del sistema.
				\end{itemize}
			\end{block}
			\column{0.48\textwidth}
			\begin{block}{\textcolor{red}{$\times$}\ Desventajas}
				\begin{itemize}
					\item Menor eficiencia respecto al codigo maquina.
					\item Mayor consumo de memoria por la abstraccion.
					\item Menor control sobre el hardware.
					\item Dependencia del compilador o interprete.
					\item No apto para programar drivers o kernels.
				\end{itemize}
			\end{block}
		\end{columns}
	\end{frame}
	
	% ============================================================
	% DIAPOSITIVA 5
	% ============================================================
	\begin{frame}{Bajo Nivel --- Ventajas y Desventajas}
		\begin{columns}
			\column{0.48\textwidth}
			\begin{block}{\textcolor{unemiNaranja}{$\checkmark$}\ Ventajas}
				\begin{itemize}
					\item Control total sobre el hardware y los recursos.
					\item Maxima eficiencia y velocidad de ejecucion.
					\item Codigo altamente optimizado para tareas criticas.
					\item Indispensable para sistemas embebidos y kernels.
					\item Sin dependencia de traductores intermedios.
				\end{itemize}
			\end{block}
			\column{0.48\textwidth}
			\begin{block}{\textcolor{red}{$\times$}\ Desventajas}
				\begin{itemize}
					\item Curva de aprendizaje muy elevada.
					\item Codigo dificil de leer, depurar y mantener.
					\item Especifico para cada arquitectura (x86, ARM, MIPS).
					\item Mayor riesgo de errores criticos de memoria.
					\item Desarrollo lento y costoso en tiempo.
				\end{itemize}
			\end{block}
		\end{columns}
	\end{frame}
	
	% ============================================================
	% DIAPOSITIVA 6: PYTHON
	% ============================================================
	\begin{frame}[fragile]{Ejemplo en Alto Nivel --- Python}
		El siguiente programa imprime un mensaje en pantalla utilizando \textbf{Python},
		lenguaje de alto nivel reconocido por su sintaxis clara y concisa:
		\vspace{0.3cm}
		\begin{lstlisting}[language=Python]
			# Programa en Python - Alto Nivel
			# Imprime un mensaje en pantalla
			
			mensaje = "Hola, Mundo!"
			print(mensaje)
		\end{lstlisting}
		\vspace{0.3cm}
		\begin{block}{Observacion}
			Con \textbf{una sola instruccion} (\texttt{print}) el programador ordena mostrar
			texto en pantalla. El lenguaje gestiona internamente la llamada al sistema
			operativo, los \textit{buffers} de salida y la codificacion del texto.
			El programador no necesita conocer ninguno de esos detalles.
		\end{block}
	\end{frame}
	
	% ============================================================
	% DIAPOSITIVA 7: PSEUDOCODIGO
	% ============================================================
	\begin{frame}[fragile]{Equivalente en Pseudocodigo}
		El mismo procedimiento expresado en \textbf{pseudocodigo}: representacion abstracta
		que describe la logica con lenguaje natural estructurado, independiente de cualquier
		lenguaje o plataforma:
		\vspace{0.3cm}
		\begin{lstlisting}[language={}]
			INICIO
			DEFINIR mensaje COMO CADENA
			mensaje <- "Hola, Mundo!"
			ESCRIBIR mensaje
			FIN
		\end{lstlisting}
		\vspace{0.3cm}
		\begin{block}{Proposito del Pseudocodigo}
			Permite disenar la logica de un algoritmo antes de codificarlo en un lenguaje
			real. No requiere compilacion ni interprete. Es la herramienta pedagogica
			fundamental en la ensenanza de algoritmos.
		\end{block}
	\end{frame}
	
	% ============================================================
	% DIAPOSITIVA 8: ENSAMBLADOR
	% ============================================================
	\begin{frame}[fragile]{Equivalente en Bajo Nivel --- Ensamblador x86 (NASM/Linux)}
		La misma tarea en \textbf{lenguaje ensamblador} requiere configurar manualmente
		los registros del procesador e invocar una interrupcion del sistema operativo:
		\vspace{0.2cm}
		\begin{lstlisting}[language={[x86masm]Assembler}]
			section .data
			msg db "Hola, Mundo!", 0x0A
			len equ $ - msg
			
			section .text
			global _start
			_start:
			mov eax, 4    ; syscall sys_write
			mov ebx, 1    ; stdout
			mov ecx, msg  ; direccion del mensaje
			mov edx, len  ; longitud del mensaje
			int 0x80      ; interrupcion al kernel
			
			mov eax, 1    ; syscall sys_exit
			xor ebx, ebx  ; codigo de salida 0
			int 0x80      ; interrupcion al kernel
		\end{lstlisting}
	\end{frame}
	
	% ============================================================
	% DIAPOSITIVA 9: LENGUAJE MAQUINA
	% ============================================================
	\begin{frame}[fragile]{El Nivel mas Bajo --- Lenguaje Maquina}
		Por debajo del ensamblador existe el \textbf{lenguaje maquina}: secuencia de bits
		que el procesador ejecuta directamente. Cada instruccion se traduce a valores
		hexadecimales y binarios:
		\vspace{0.2cm}
		\begin{lstlisting}[language={}]
			Instruccion: int 0x80
			Hex    : CD 80
			Binario: 11001101  10000000
			
			Instruccion: mov eax, 4
			Hex    : B8 04 00 00 00
			Binario: 10111000  00000100  00000000  00000000  00000000
			
			Instruccion: mov ebx, 1
			Hex    : BB 01 00 00 00
			Binario: 10111011  00000001  00000000  00000000  00000000
		\end{lstlisting}
		\vspace{0.1cm}
		\begin{block}{Reflexion}
			Es el unico lenguaje que la CPU comprende de forma nativa. El ensamblador
			surgio para liberar al programador de escribir directamente en binario.
		\end{block}
	\end{frame}
	
	% ============================================================
	% DIAPOSITIVA 10: COMPARACION
	% ============================================================
	\begin{frame}{Comparacion Directa}
		\centering
		\textbf{Tarea: Imprimir ``Hola, Mundo!'' en pantalla}
		\vspace{0.4cm}
		\begin{columns}
			\column{0.30\textwidth}
			\begin{block}{\centering Alto Nivel (Python)}
				\centering
				\vspace{0.15cm}
				\texttt{\small print("Hola, Mundo!")} \\[0.2cm]
				\textbf{1 linea de codigo}
				\vspace{0.1cm}
			\end{block}
			\column{0.36\textwidth}
			\begin{block}{\centering Ensamblador (NASM)}
				\centering
				\vspace{0.1cm}
				\small
				Definir seccion de datos \\
				Cargar registros eax, ebx \\
				Asignar ecx y edx \\
				Invocar interrupcion 0x80 \\[0.1cm]
				\textbf{$\approx$14 lineas de codigo}
				\vspace{0.1cm}
			\end{block}
			\column{0.28\textwidth}
			\begin{block}{\centering Lenguaje Maquina}
				\centering
				\vspace{0.1cm}
				\small
				\texttt{B8 04 00 00 00} \\
				\texttt{BB 01 00 00 00} \\
				\texttt{CD 80 \ldots} \\[0.1cm]
				\textbf{Solo 0s y 1s}
				\vspace{0.1cm}
			\end{block}
		\end{columns}
		\vspace{0.35cm}
		\small La misma tarea requiere un nivel de detalle radicalmente distinto
		segun la abstraccion del lenguaje utilizado.
	\end{frame}

	\begin{frame}{Cuando usar cada tipo?}
		\begin{columns}
			\column{0.48\textwidth}
			\begin{block}{Se usa Alto Nivel cuando\ldots}
				\begin{itemize}
					\item Se desarrollan aplicaciones web, moviles o de escritorio.
					\item El tiempo de desarrollo es critico.
					\item Se trabaja con inteligencia artificial o ciencia de datos.
					\item La portabilidad entre plataformas es necesaria.
					\item El equipo de trabajo es amplio y diverso.
				\end{itemize}
			\end{block}
			\column{0.48\textwidth}
			\begin{block}{Se usa Bajo Nivel cuando\ldots}
				\begin{itemize}
					\item Se programan sistemas operativos o kernels.
					\item Se desarrollan controladores de hardware (drivers).
					\item Se trabaja con sistemas embebidos o IoT.
					\item La eficiencia maxima de ejecucion es imprescindible.
					\item Se realiza ingenieria inversa o analisis de malware.
				\end{itemize}
			\end{block}
		\end{columns}
	\end{frame}
	
	% ============================================================
	% DIAPOSITIVA 13
	% ============================================================
	\begin{frame}{Conclusiones}
		\begin{block}{Sintesis}
			\begin{itemize}
				\item Los lenguajes de \textbf{alto nivel} priorizan la productividad del
				desarrollador y la legibilidad, a costa de menor control del hardware.
				\item Los lenguajes de \textbf{bajo nivel} priorizan el rendimiento y el control
				directo del procesador, a costa de mayor complejidad.
				\item \textbf{Ninguno reemplaza al otro}: coexisten y se complementan segun
				el contexto del proyecto.
				\item La comprension del bajo nivel permite escribir codigo de alto nivel mas
				eficiente y consciente de los recursos del sistema.
			\end{itemize}
		\end{block}
		\vspace{0.3cm}
		\centering
		\textit{``Conocer como funciona la maquina a nivel profundo convierte a un
			programador de alto nivel en un mejor ingeniero de software.''}
	\end{frame}
